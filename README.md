# Quiz Application

A beginner Python project that asks users a series of questions, checks their answers, calculates the final score, and displays the percentage obtained.

## 🚀 Features

* Asks multiple quiz questions
* Accepts user answers as input
* Checks answers automatically
* Displays whether each answer is correct or incorrect
* Shows the correct answer when a mistake is made
* Calculates final score
* Calculates percentage
* Displays a final quiz report

## 🧠 Concepts Used

* Variables
* Strings
* Lists
* User Input
* If-Else Statements
* Loops (`for`)
* Functions
* Score Tracking
* Basic Calculations

## 🎯 Purpose

This project was built to practice Python fundamentals including loops, lists, functions, conditional statements, user input handling, and score calculation through an interactive quiz application.
